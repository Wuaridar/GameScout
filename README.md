# GameScout MVP

Первая черновая версия интерфейса агрегатора цен на игры.

## Как открыть

1. Откройте файл `index.html` в браузере.
2. Попробуйте запросы:
   - Dead by Daylight
   - Overwatch 2
   - Cyberpunk 2077

## Что уже работает

- Поисковая строка
- Демонстрационная база игр
- Сортировка предложений по цене
- Адаптивная мобильная вёрстка
- Заготовки под Steam, GGSell, Battle.net и GOG

## Что пока не подключено

- Реальные API и парсинг магазинов
- Сервер и база данных
- Личный кабинет
- История цен
- Уведомления
- Партнёрские ссылки
